Rulings (2026-10-16, in the epic PM session; 「同意」 to the four points as drawn, then 「studio 中其他的设计面板属性都是右侧打开的，你换到 tab 会不会改动太大，是否考虑浮出」and「属性好需要考虑选中每个元素的时候也要显示。」which first turned the copilot into a floating panel beside the properties rail (「按浮窗版定稿」), then「ai 副驾或者属性面板是否能切换隐藏，这个宽屏的界面好乱。还有我在和ai 讨论的时候估计也不会看属性吧？」which replaced it with one right slot that shows either the properties or the copilot (「按「右栏二选一」定稿」), and「源码的选项卡有必要保留吗？未来还有人看吗」which removed the 源码 tab): first build publishes at once, later changes to a live app with data are saved as a draft; the plan card shows the full detail; overdue = status 逾期 and 归还日期 empty; sample data defaults to 12 rows per object with uniqueness and format checks.
