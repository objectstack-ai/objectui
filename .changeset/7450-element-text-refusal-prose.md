Message text only: the refusal an `element:text` node draws for an authored `body` or `children` describes what the block renders in the converged `variant` vocabulary, the heading level (`h1`-`h6`) or the paragraph style (`body`, `caption`, `overline`), where it used to say "a heading, subheading or paragraph" (objectui#7450). No accepted or refused value moves.
