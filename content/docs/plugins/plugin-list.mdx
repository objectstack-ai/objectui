# @object-ui/plugin-list

ListView plugin for Object UI - unified view component with view type switching

## Installation

```bash
pnpm add @object-ui/plugin-list
```

## On a page — `requiredPermissions`

A page `list-view` node is written in `@objectstack/spec`'s list view spelling,
with its keys in `properties`. `requiredPermissions` gates what the node draws:

```json
{
  "type": "list-view",
  "properties": {
    "data": { "provider": "object", "object": "deal" },
    "requiredPermissions": ["sales.view_pipeline"]
  }
}
```

`requiredPermissions` lists capabilities the viewer must all hold. A viewer
missing one sees "Insufficient permissions to view list." in place of the list,
as the record blocks show, and no records are queried.

`addRecord` and `sharing` are not published inputs of a page node yet: the Add
button is drawn only under a host that serves the object's create handler, and
the Share button has no action the spec declares.
