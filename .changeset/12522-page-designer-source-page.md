Studio, Interfaces pillar: an html or react page reads like a code page. The source editor's plain-text fallback numbers its lines and wraps long ones as the code editor does, and a line under the editor says "Saved HH:MM" or "Unsaved". The page's Properties tab now shows its label (editable), its identifier, the language it is written in and the navigation entries that open it. The Design / Run switch is disabled on such a page, with a tooltip saying why: Run draws exactly what Design draws.
