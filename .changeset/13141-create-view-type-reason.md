Create View dialog: a view type the object cannot support now says why on its card ("This object has no field that can serve as …" or "This object exposes no dataset to chart."), as visible text and as the card's accessible description, instead of only in a tooltip on a disabled button. Type descriptions are no longer cut mid-line: the type grid shows three columns at dialog width (two on a phone).
