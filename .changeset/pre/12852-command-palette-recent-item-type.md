The command palette's recently viewed rows now show what each item is: the record's object label on the right (in the viewer's language) and the object's icon on the left, in place of the same search icon on every row. Two recent records with the same name but different objects — an organisation and its environment, say — no longer look identical. A record whose stored address names no object shows no type and a neutral record icon.
